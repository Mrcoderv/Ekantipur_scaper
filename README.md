# ekantipur.com Scraper


A Playwright-based web scraper that extracts entertainment news and the cartoon of the day from [ekantipur.com](https://ekantipur.com).

---

## What It Does

**Task 1 — Top 5 Entertainment Articles**
Navigates to the मनोरञ्जन (entertainment) section and extracts:
- Article headline (title)
- Thumbnail image URL
- Category label in Nepali
- Author name (null if not available)

**Task 2 — Cartoon of the Day**
Finds the व्यंग्यचित्र (cartoon) section and extracts:
- Cartoon title or caption
- Direct image URL
- Cartoonist name

## Setup

### 1. Install uv (if not already installed)

**macOS / Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env
```
## Windows (PowerShell)

Install `uv`:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Restart PowerShell after installation, or run:

```powershell
$env:Path = "C:\Users\Acer\.local\bin;$env:Path"
```

Verify installation:

```powershell
uv --version
```

---

## 2. Initialize the project

Inside the project folder:

```powershell
uv init
```

This creates the required `pyproject.toml` file.


### 2. Install dependencies
```bash
uv add playwright
```

### 3. Install Playwright browser
```bash
uv run playwright install chromium
```

---

## Running the Scraper

```bash
uv run python scraper.py
```

The browser will open visually (`headless=False`) so you can watch it work.
When complete, `output.json` will be saved in the project folder.

## How Selectors Were Found

All selectors were identified manually using Chrome DevTools (F12):

| Data | Selector Used |
|------|--------------|
| Article cards | `div.category-inner-wrapper` |
| Article title | `div.category-description h2 a` |
| Article image | `div.category-image img` |
| Author link | `a[href*='/author/']` |
| Cartoon section | `section.e-section .cartoon-slider` |
| Active cartoon slide | `.swiper-slide-active img` |
| Cartoon description | `div.cartoon-description p` |

## Key Technical Decisions

**Lazy image loading**
The site uses lazy loading — images are stored in `data-src` instead of `src` until they scroll into view. The scraper checks `src`, `data-src`, and `data-original` in order.

**Cartoon matching**
The carousel on the homepage and the listing on `/cartoon` are two separate pages. The scraper matches the correct cartoon by comparing image URLs and alt text between both pages to get the cartoonist name.

**Error handling**
Every element access is wrapped in `try/except`. If a field is missing, it returns `null` instead of crashing. The script always writes `output.json` even if some data could not be extracted.

**Nepali text**
`json.dump` uses `ensure_ascii=False` so Devanagari characters are written correctly instead of as unicode escape codes like `\u092e`.
